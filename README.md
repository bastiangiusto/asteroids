# Asteroids

A Python and Pygame clone of the classic Asteroids arcade game, built as part of the boot.dev backend learning path.

## Features

- Move and rotate the player ship
- Shoot projectiles at asteroids
- Asteroids split into smaller pieces when hit
- Collision detection between the ship, projectiles, and asteroids

## Installation and Usage

1. Install the dependencies from the lockfile:

   uv sync

2. Start the game:

   uv run main.py
